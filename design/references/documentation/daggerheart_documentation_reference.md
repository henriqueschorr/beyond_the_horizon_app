# Codex Presentation & UX Report: *Daggerheart*
*An exhaustive analysis of Information Architecture, Editorial-Card Hybrid Layouts, Hope & Fear Visual Duality, and Modern Narrative Typography in Darrington Press's Flagship TTRPG.*

---

## Executive Summary

*Daggerheart* (created by **Spenser Starke** and **Matthew Mercer**, published by **Darrington Press**) represents the forefront of modern narrative-heroic tabletop design. Debuting to critical and commercial acclaim in 2024/2025, *Daggerheart* bridges the gap between traditional d20 tactical systems (like D&D 5e) and modern story games (like *Powered by the Apocalypse* and *Forged in the Dark*).

From an information architecture perspective, *Daggerheart* solves one of the oldest problems in RPG publishing: **how to represent complex multi-tier class abilities without overwhelming players with pages of dense spell and power tables**. It achieves this through a revolutionary **Editorial-Card Hybrid Architecture**, **Hope/Fear Visual Duality**, and **Asymmetrical Dossier Spreads**.

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    THE CORE DESIGN AXIOMS OF DAGGERHEART                │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. The Editorial-Card Hybrid: The core rulebook does not act as an      │
│    encyclopedic list of 500 spells; it interfaces directly with a       │
│    physical/digital deck of modular Domain Cards.                       │
│ 2. The Hope & Fear Duality: The core resolution mechanic (2d12 Hope vs  │
│    Fear) is mirrored visually throughout the layout—warm golden sun-    │
│    bursts vs deep obsidian/violet shadows.                              │
│ 3. Asymmetrical Dossier Spreads: Left column is an inverted dark dossier│
│    of identity and stats; right column is an airy editorial rule space. │
│ 4. Conversational Player Onboarding: Every class and subclass opens     │
│    with an italicized, direct goal statement: "Play the X if you..."    │
│ 5. Dutch Editorial Typography: Replaces generic fantasy fonts with      │
│    Questa Slab and Eveleth, giving the book a warm, artisanal elegance. │
```

## 1. Information Architecture & Macro-Organization

Spanning 415 pages in standard 8.5 x 11 inch format, *Daggerheart* structures its narrative engine into five meticulously staged chapters:

```
[ FRONT MATTER ] ──> P.1-10:   Introduction & Player Principles
[ CHAPTER ONE  ] ──> P.11-86:  Preparing For Adventure (World, Creation, Classes)
[ CHAPTER TWO  ] ──> P.87-139: Playing an Adventure (Flow, Duality Dice, Combat)
[ CHAPTER THREE] ──> P.140-192: Running an Adventure (GM Moves, Fear Engine, Prep)
[ CHAPTER FOUR ] ──> P.193-360: Adversaries and Environments (Stat Cards & Biomes)
[ CHAPTER FIVE ] ──> P.361-415: Campaigns, World Frames & Appendix
```

### A. The In-Engine Progression Logic
1. **World Overview First (P.11)**: Instead of plunging into mathematical stat rolls, the book establishes the cinematic tone and narrative consensus.
2. **Class-Before-Ancestry Architecture (P.27-51)**: Recognizing that a player's combat role and active playstyle dictate their experience, classes come *before* ancestries and communities.
3. **The Subclass Pyramid (Foundation, Specialization, Mastery)**: Abilities are presented in three clear vertical tiers rather than scattered level-by-level tables.

## 2. Page Geometry & The Asymmetrical Dossier Spread

```
┌──────────────────────────────────────┬──────────────────────────────────┐
│ [ DARK DOSSIER SIDEBAR ]             │ [ LIGHT EDITORIAL RULES ]        │
│                                      │                                  │
│ BARD                                 │ BARD SUBCLASSES                  │
│ Bards are the most charismatic...    │ Choose either Troubadour or...   │
│                                      │                                  │
│ 🟩 GRACE & CODEX (Domains)           │ TROUBADOUR                       │
│                                      │ Play the Troubadour if you...    │
│ STARTING EVASION: 10                 │                                  │
│ STARTING HP: 5                       │ ■ SPELLCAST TRAIT: Presence      │
│ CLASS ITEMS: A romance novel...      │                                  │
│                                      │ ■ FOUNDATION FEATURE             │
│ BARD'S HOPE FEATURE                  │   - Relaxing Song                │
│ Spend 1 Hope to temporarily distract │   - Epic Song                    │
│                                      │                                  │
│ CLASS FEATURE: Rally                 │ ■ SPECIALIZATION FEATURE         │
│ Roll your Rally Die once per session │                                  │
│                                      │ ■ MASTERY FEATURE                │
│ [ CHARACTER ARTWORK OVERFLOW ]       │                                  │
│ (Swirling golden magic ribbons       │                                  │
│  bleed across into the right page)   │ [ RUNNING FOOTER: P.29 Chapter 1]│
└──────────────────────────────────────┴──────────────────────────────────┘
```

### A. The Dual-Tone Contrast Column
On every class spread (such as *Bard* on P.28-29, *Ranger* on P.38-39):
- **The Left Third (Dark Dossier Column)**: Filled with a solid deep charcoal slate (`#2A272C`). White and light grey text houses the character's intrinsic identity: Core Concept, Domain badges, Evasion, HP, Class Items, and unique Class Features.
- **The Right Two-Thirds (Warm Parchment Column)**: An airy, warm-white editorial page (`#FAF8F5`) housing subclass choices, progression features, and mechanical rules.
- **Artistic Bleed**: High-detail character artwork is anchored in the lower-left dark column, but magical energy, weapons, or cloaks break free and swirl across the column boundary into the light page, unifying the spread.

### B. The Running Footer Navigation
At the base of the page runs a thin dual-line golden rule accompanied by a chapter badge:
- **Left/Right Badges**: Solid ochre/yellow rectangular box containing the page number (`28`).
- **Chapter Breadcrumb**: Direct label in small caps (`Chapter 1: Class`, `Chapter 2: Core Mechanics`).

## 3. Typographic Identity & Editorial Hierarchy

*Daggerheart*'s typographic system was designed to feel like an illuminated literary magazine—warm, legible, and distinctly artisanal.

```
   ____                                _                         _   
  |  _ \  __ _  __ _  __ _  ___ _ __  | |__   ___  __ _ _ __ ___| |_ 
  | | | |/ _` |/ _` |/ _` |/ _ \ '__| | '_ \ / _ \/ _` | '__/ __| __|
  | |_| | (_| | (_| | (_| |  __/ |    | | | |  __/ (_| | |  \__ \ |_ 
  |____/ \__,_|\__, |\__, |\___|_|    |_| |_|\___|\__,_|_|  |___/\__|
               |___/ |___/                                           
```

### A. Exact Font Families & Roles

| Role | Exact Font Identified in PDF | Characteristics & Psychological Tone |
|---|---|---|
| **Primary Display Titles** | **Eveleth Clean Regular & Thin** | Hand-crafted, all-caps rustic letterpress sans with subtle geometric distress. Used for Class titles, Chapter openers, and weapon headers. |
| **Editorial Slab & Subheads** | **Questa Slab (Medium & Bold Italic)** | A Dutch modern slab-serif by Martin Majoor & Jos Buivenga. Combines neoclassical elegance with sharp, sturdy serifs for feature headers. |
| **Interface & Section Labels** | **Questa Sans (Medium & Light Italic)** | Sans-serif sister font to Questa Slab; used for domain cards, item statistics, and table headers. |
| **System Rules & Micro-Copy** | **Overpass (Regular, SemiBold, Black)** | Grotesque sans-serif inspired by Highway Gothic. Ultra-clean readability on screens and print, used for stat numbers and bulleted mechanics. |
| **Narrative Body Text** | **Minion Pro (Regular & Italic)** | Classical Adobe book serif with balanced proportions and humanist warmth, used for lore paragraphs and world descriptions. |

### B. Typographic Hierarchy in Action
- **`H1` Major Section**: *Eveleth Clean* (36pt-48pt, All Caps, Light Tracking).
- **`H2` Subclass / Monster Category**: *Questa Slab Bold* (20pt-24pt, Warm Gold `#C28B23`).
- **`H3` Ability Tiers**: *Questa Slab Medium* (14pt, Small Caps, preceded by gold square glyph `■`).
- **Body & Mechanics**: *Overpass Regular* (9.5pt on 13.5pt leading) for rules; *Minion Pro* for narrative fiction.

## 5. Presentation of Rules vs Lore: The Conversational Pivot

*Daggerheart* rejects both dry clinical rule-writing and impenetrable walls of fantasy prose. Instead, it uses **Intent-Based Player Onboarding**:

```
[ CONVERSATIONAL HOOK ]  ──> "Play the Troubadour if you want to play music to bolster your allies."
           ↓
[ MECHANICAL KEYWORD ]   ──> "SPELLCAST TRAIT: Presence"
           ↓
[ PROGRESSION TIERS ]    ──> "■ FOUNDATION FEATURE: Gifted Performer"
                             "■ SPECIALIZATION FEATURE: Maestro"
                             "■ MASTERY FEATURE: Virtuoso"
```

1. **The "Play This If You Want To..." Anchor**:
   Before reading a single rule about a class or subclass, players are greeted with a single italicized sentence summarizing the mechanical and narrative fantasy. This drastically accelerates session zero character selection.
2. **Adversary Intent Over Stat Multiplication**:
   Monsters in Chapter Four are organized not merely by challenge rating, but by **Tactical Role**: *Leader, Bruiser, Minion, Skulker, Support*. Each adversary has explicit scripted **GM Fear Moves** that turn abstract hit points into visceral narrative actions.

## 6. The Card Ecosystem & Digital HUD Implications

*Daggerheart* is designed from the ground up as a **dual physical-and-digital product**. The book's layout directly prepares players for card-deck interactions:

- **Modular Card Slots**: Abilities in the book match the exact dimensions and visual hierarchy of the physical print-and-play and digital cards.
- **Action Trays**: Character sheets feature dedicated cutout wells for holding active domain cards, equipped weapons, and stress markers.
- **Evasion & Damage Thresholds**: Damage is not tracked through subtracting 37 HP from 150. Characters have three thresholds: *Minor, Major, Severe*, which convert incoming damage into 1, 2, or 3 Hit Point pips. The rulebook lays this out with visual meters rather than algebraic equations.

## 7. Key Takeaways & Actionable Codex UX Strategies

1. **Asymmetrical Split-View (The Dossier/Rule Split)**:
   - For character builders or unit profiles in a digital application, adopt a split screen: an inky dark left pane for immutable identity and current stats, and an airy light right pane for active rules and progression choices.
2. **Intent-Driven Selection Prompts**:
   - Always head complex mechanical options with a 1-sentence "Select this if you want to..." summary.
3. **Dual-Tone Polarity Lighting**:
   - When a system has two driving philosophical forces (Hope vs Fear, Light vs Void, Sanity vs Madness), use distinct color tokens across the entire UI to immediately tag which system an action feeds.
4. **Superfamily Typography (Slab + Sans Pairings)**:
   - Pairing a sturdy slab-serif for headers (like Questa Slab) with an ultra-readable grotesk sans (like Overpass) creates an authoritative yet modern, non-stuffy aesthetic.
