# 0001: Codex-First Scope and 5-Phase Lifecycle

- **Status:** accepted
- **Date:** 2026-10-20

## Context & Decision
The initial project planner scheduled authentication, compendium, character creation, interactive sheets, real-time injury logs, and facilitator dashboards into Phase 1, creating an unmanageable scope before core rules could even be read. We decided to restructure the roadmap into 5 clear phases: Phase 1 (Rules Compendium and Codex MVP), Phase 2 (Character Creation and Play Sheet), Phase 3 (Atmospheric Polish and Micro-Animations), Phase 4 (Facilitator and Campaign Operations), and Phase 5 (The Mind Place and Advanced Expansions).

## Consequences
- Positive: Delivers immediate, high-impact value to players and game masters who need to read and reference rules. Provides clean thematic separation between functional toolsets and visual polish.
- Trade-offs: Digital character sheets and dice rolling are postponed to Phase 2.
