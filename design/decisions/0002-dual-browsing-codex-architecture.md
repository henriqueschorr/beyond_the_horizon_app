# 0002: Dual Browsing Information Architecture

- **Status:** accepted
- **Date:** 2026-10-20

## Context & Decision
Tabletop companions often fail by forcing players either into purely linear PDF-style readers (terrible for looking up weapons mid-combat) or purely fragmented wikis (terrible for learning the game sequentially). We decided to adopt the dual browsing architecture established by D&D Beyond: Sources for continuous chapter reading, and Game Rules for filterable entity databases, connected seamlessly by non-destructive slide-over drawers.

## Consequences
- Positive: Serves both the study state (reading front-to-back) and the play state (instant tactical filtering) without forcing compromises on either.
- Trade-offs: Requires maintaining both linear manuscript chapters and structured entity metadata.
